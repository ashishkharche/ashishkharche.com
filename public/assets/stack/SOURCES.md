# Stack icon sources

Icons for the Stack section of the Workout Director case study. Fetched on 1 and 2 November 2026. Each mark is
used only to name the tool next to it, in a list of what the app is built with; nothing here suggests the owner
endorses or sponsors the app. The marks remain trademarks of their owners.

Simple Icons files come from the npm package `simple-icons` 16.36.0 (https://simpleicons.org,
https://github.com/simple-icons/simple-icons). The package is released under CC0 1.0 (its `LICENSE.md` is the CC0 1.0
Universal text). Its `DISCLAIMER.md` says CC0 covers the package and not necessarily each brand, and asks users to
check each brand's guidelines, so the owner's terms were checked for every item below. The single-colour files keep
the Simple Icons path exactly and only set the fill: `#090a0b` (the site's text colour) for `*-dark-ink.svg`, shown on
the light theme, and `#f1f6f3` for `*-light-ink.svg`, shown on the dark theme.

Items whose owner restricts the mark, or that have no mark, get a neutral letter tile drawn in the site's own type
(Geist, in a rounded square). The letters are not a logo and do not copy one.
