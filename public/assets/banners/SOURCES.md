## Artwork and composition

Note 1 pairs an existing squat figure with a static Live Coach concept. The displayed count is a design placeholder, not observed results. It is not a network-flow diagram or evidence of released functionality.
Note 2 uses saved push-up rig coordinates and existing finished line art. It does not show a newly verified pose match or accuracy result.
Selected work uses the outlined WD identity with squat and trainer concepts. Trainer conversation is synthetic, not a private message or actual result.

## Reflex note banner

`note-reflex-runner-1600x900.webp`, `note-reflex-runner-1200x630.png` and `note-reflex-runner.svg` were redrawn on 10 November 2026 as a clean wordmark banner. The prism mark and the outlined “Reflex” wordmark come from the official lockup in the Reflex repo (MIT, github.com/ashishkharche/reflex, `assets/brand/lockup-light.svg`). The wordmark is Space Grotesk SemiBold (weight 600), the font used in that repo’s README header (`assets/brand/fonts/SpaceGrotesk-SemiBold.ttf`, documented in `assets/brand/fonts/LICENCES.md`). Space Grotesk is SIL Open Font Licence 1.1 (`assets/brand/fonts/SpaceGrotesk-OFL.txt`), which allows use and embedding in documents. The letters are outlined as SVG paths so the site does not ship the font file. The ground is the site off-white `#faf8f3`. There is no frame, title, footer or diagram label. The Open Graph card `public/assets/og/notes-reflex.png` is the 1200 by 630 crop of this banner.
